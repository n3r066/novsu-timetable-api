## Формат Поста Изменений

Новый шаблон строится функцией `format.build_changes_rich_message`:

1. День и конкретное действие: «Понедельник · изменили название».
2. Предмет и сама правка: прежнее название или старое значение → новое.
Юнит монитора больше не передаёт `--update-post`, id берётся из окружения.

3. Время, неделя и место без пустых значений; разные условия верхней и нижней недели подписаны отдельно.
4. Неизменившийся преподаватель и дополнительный контекст в закрытых «Деталях занятия».
5. Закрытое сравнение скриншотов «Было / Стало», если они доступны.
6. Одна ссылка на источник в подвале; счётчик только при нескольких правках.

Нет «Коротко», повторных заголовков, открытых разделов дней и цитат вокруг каждой правки. Дата публикации остаётся штатной датой Telegram. Основной закреп не затрагивается. Актуальные ограничения и правила: `docs/OPERATIONS.md`, раздел «Change notification layout».

## Важное Ограничение Telegram

Bot API не может редактировать сообщение, созданное другим аккаунтом или другим ботом. Поэтому ID 120 (пользовательский) и ID 3 (старый бот) нельзя использовать как рабочий автоматически обновляемый пост. Для автоматического дашборда используется ID 184 нового бота.

Не закреплять ID 134 без отдельной команды пользователя.
