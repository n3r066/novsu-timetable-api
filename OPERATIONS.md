## Telegram-Посты

- **Пост 3** — основной дашборд расписания. Его редактирует монитор.
- **Пост 120** — старый пост изменений, создан пользовательским аккаунтом. Бот не может его редактировать.
- **Пост 132** — ошибочная копия основного расписания, удалён.
- **Пост 134** — копия поста изменений в новом формате. Создан ботом, оставлен в канале без закрепления.

Пост 134 не является рабочим дашбордом и не должен закрепляться автоматически.

Текущая автоматика обновляет только пост 3:

```text
--update-post 3
NOVSU_DASHBOARD_POST_ID=3
```

## Формат Поста Изменений

Новый шаблон строится функцией `format.build_changes_rich_message`:

1. Шапка: «Поменяли расписание», количество, дата и неделя.
2. «Коротко» — сводка по дням.
3. «Что именно поменяли» — раскрываемые карточки по дням.
4. Скрин изменённого дня, если он успешно отрендерен.
5. Пояснения только при наличии реального пояснения.

Из дифф-поста убраны повторяющаяся легенда времени, пустой блок «Как это читать» и дублирующий источник внизу. Ссылка на портал остаётся в карточке дня, если прикреплён скрин.

## Сервисы

- `novsu-timetable-monitor.service` — монитор, активен и включён.
- `novsu-timetable-api.service` — JSON API на `127.0.0.1:8787`, активен и включён.
- `novsu-timetable-rollover.timer` — ночной ролловер основного дашборда.

Проверки:

```bash
systemctl status novsu-timetable-monitor.service
systemctl status novsu-timetable-api.service
curl http://127.0.0.1:8787/health
```

## Важное Ограничение Telegram

Bot API не может редактировать сообщение, созданное пользовательским аккаунтом. Поэтому ID 120 нельзя использовать как рабочий автоматически обновляемый пост. Для автоматического дашборда используется ботский ID 3.

Не закреплять ID 134 без отдельной команды пользователя.
